# 週次予材リスト同期スクリプト (Google Apps Script)

Google Driveフォルダ内のExcel/スプレッドシートを読み取り、「31期予材リスト」スプレッドシートの
「週次報告記録」シート末尾に自動追記するGASスクリプトです。

- 取得元フォルダ: `1WrjMUtIpe2JEwChiJygRs1TeqWGgPuyc`
- 追記先スプレッドシート: `1zTz2lLUD6M4SPBCcEO3OBxNMmv1U7RsUYRJhkKkgOOQ`（シート「週次報告記録」）

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `appsscript.json` | マニフェスト。Drive API (Advanced Service, v3) を有効化する設定を含む |
| `Config.gs` | フォルダID・シート名などの設定値 |
| `WeeklySync.gs` | メイン処理 (`syncWeeklyReports`) |
| `Triggers.gs` | 週次トリガーをスクリプトから設定するためのヘルパー (`installWeeklyTrigger`) |

## 処理内容

1. `SOURCE_FOLDER_ID` フォルダ直下のファイルを走査し、Googleスプレッドシート/Excel(.xlsx/.xls)のみ対象にする。
2. Excelファイルは一時的にGoogleスプレッドシート形式へ変換して1シート目のデータを読み取り、変換用の一時ファイルは処理後にゴミ箱へ送る。
3. 各行の先頭に「取込日時」「元ファイル名」を付与し、「週次報告記録」シートの末尾へ1ファイルずつまとめて追記する（1行目はヘッダーとして読み飛ばす設定: `SOURCE_HAS_HEADER`）。
4. 追記が終わったファイルは `処理済み` サブフォルダへ移動し、次回以降のスキャン対象から除外することで二重処理を防止する。
5. 読み取りや書き込みに失敗したファイルは `エラー` サブフォルダへ移動し、`NOTIFY_EMAIL` を設定していればエラー内容をメール通知する。

`処理済み`・`エラー` フォルダは `SOURCE_FOLDER_ID` の直下に初回実行時に自動作成されます。

## セットアップ手順

1. [script.google.com](https://script.google.com) で新規プロジェクトを作成する（「31期予材リスト」に紐づくコンテナバインド型でも、スタンドアロン型でもどちらでも可）。
2. `appsscript.json` の内容をプロジェクトのマニフェストに反映する（エディタ左のプロジェクトの設定で「"appsscript.json" マニフェスト ファイルをエディタで表示する」を有効にすると直接編集できる）。
3. `Config.gs` / `WeeklySync.gs` / `Triggers.gs` の内容をそれぞれ同名のスクリプトファイルとして貼り付ける。
4. 左メニュー「サービス」の「+」から **Drive API** (Advanced Google Service, v3) を追加する。
   - 併せてGoogle Cloud PlatformプロジェクトでもDrive APIが有効化されていることを確認する（初回追加時にリンクが表示される）。
5. エディタ上部の関数選択で `syncWeeklyReports` を選び、一度手動実行して権限承認（Drive・スプレッドシートへのアクセス許可）を行う。
6. 実行ログ (表示 → 実行数、またはログ) で正常終了・追記結果を確認する。

## 週次トリガーの設定手順

### 方法A: GASエディタから手動設定（推奨）

1. エディタ左メニューの時計アイコン「トリガー」を開く。
2. 右下「トリガーを追加」をクリック。
3. 以下を設定して保存する。
   - 実行する関数を選択: `syncWeeklyReports`
   - 実行するデプロイを選択: `Head`
   - イベントのソースを選択: `時間主導型`
   - 時間ベースのトリガーのタイプを選択: `週タイマー`
   - 曜日を選択: 任意（例: 月曜日）
   - 時刻を選択: 任意（例: 午前6時〜7時）
4. 保存すると一覧に週次トリガーが表示される。

### 方法B: スクリプトから設定

エディタ上部の関数選択で `installWeeklyTrigger` を選び、一度実行する。
毎週月曜6時台に `syncWeeklyReports` を実行するトリガーが作成される（既存の同名トリガーがあれば作り直される）。
曜日・時刻を変えたい場合は `Triggers.gs` の `onWeekDay(...)` / `atHour(...)` を編集する。

## 補足・前提条件

- 取り込むのは各ファイルの **1シート目のみ**。複数シートを取り込みたい場合は `WeeklySync.gs` の `appendFileToTargetSheet_` を修正して `getSheets()` をループする。
- 元ファイルの列構成はそのまま「週次報告記録」に追記される（先頭に取込日時・元ファイル名の2列を付与）。ファイルごとに列数が異なる場合は行ごとに列数がずれるので、取り込み元の列構成は事前に揃えておくことを推奨する。
- `Config.gs` の `NOTIFY_EMAIL` にメールアドレスを設定すると、処理失敗時のみ通知メールが届く。
